# ダッシュボードを目視で確認する

## サンプルを開く

[README のローカル開発手順](../README.md#ローカルで開発する)で起動し、`http://127.0.0.1:5173/` を開きます。画面はサンプルイベントを読み、リクエストを受けた時点で集計します。

1. プロジェクトが `demo` であることを確認します。2026年11月26日を含む期間を選び、グラフの11月26日にポインターを乗せ、DAU が **27**、PV が **36** であることを確認します。
2. 「DAU」と「PV」を切り替えます。グラフ上にポインターを乗せると、日付と値が表示されます。「日別 CSV をダウンロード」で同じ期間の値を取得できます。
3. 「流入元別セッション」で日ごとの積み上げ棒を確認します。「件数」と「構成比」を切り替え、棒にポインターを乗せるとその日の流入元別件数と割合が表示されます。凡例には選択期間全体の件数と割合が表示されます。
4. 「期間」を直近7日・14日・30日・半年（180日）に切り替え、日付の範囲、CSV の行数、流入元の集計が変わることを確認します。
5. DAU と PV のグラフにそれぞれ初期値30・40の目標ラインが表示されます。「目標値」を変更し、入力欄から離れるとラインが移動します。空欄にするとラインが消えます。目標値はプロジェクトと指標ごとに閲覧中のブラウザーに保存されます。
6. [README の手順](../README.md#ローカルで開発する)で API のレスポンスを保存し、「集計 JSON を開く」から選びます。「ローカルファイルを表示中」と表示され、保存した期間の数値が表示されることを確認します。

## 遅れて届いたイベントを反映する

ダッシュボードを開いたまま、別のターミナルで次のコマンドを実行します。11月26日に発生し、翌日に届いたページビュー5件をサンプルイベントに加えます。

```sh
pnpm run demo:prepare --include-late
```

「最新の集計を読む」を押します。11月26日の DAU が **32**、PV が **41** に変わり、最終集計の時刻が進みます。元に戻すには `pnpm run demo:prepare` を実行して、「最新の集計を読む」を押します。

本番では、集計の基準時刻から1時間が経過した後のリクエストで、クエリサーバーが DuckDB で集計し直します。本番の設定と初回公開時の確認は [デプロイと運用](deploy.md) を参照してください。
